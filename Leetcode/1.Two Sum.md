# Two Sum Problem

## Approach

The problem requires us to find two indices in an array whose elements sum up to a given target value.

## Approaches

### 1. Brute Force Approach
- **Time Complexity:** O(N^2)
- **Space Complexity:** O(1)
- **Idea:** Iterate through every pair of elements and check if their sum equals the target.
- **Implementation:**
```python
class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]:
        for i in range(len(nums)):
            for j in range(i + 1, len(nums)):
                if nums[i] + nums[j] == target:
                    return [i, j]
        return []
```

### 2. HashMap / Dictionary Approach (Optimized)
- **Time Complexity:** O(N)
- **Space Complexity:** O(N)
- **Idea:** Instead of using a brute force O(N^2) approach, we use a hashmap (unordered_map in C++ and dictionary in Python) to store the indices of elements seen so far.

### Steps:
1. Initialize an empty hashmap.
2. Iterate through the list:
   - Compute the complement (`target - current_element`).
   - If the complement exists in the hashmap, return the current index and the index of the complement.
   - Otherwise, store the current element's index in the hashmap.
3. Return an empty list if no solution exists.

#### C++ Implementation
```cpp
#include <vector>
#include <unordered_map>
using namespace std;

class Solution {
public:
    vector<int> twoSum(vector<int>& nums, int target) {
        unordered_map<int, int> map;

        for (int i = 0; i < nums.size(); i++) {
            int comp = target - nums[i];
            
            if (map.count(comp)) {
                return {map[comp], i};
            }
            
            map[nums[i]] = i;
        }
        
        return {};
    }
};
```
#### Python Solution
```python
from typing import List

class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]:
        pairs = {}

        for i, num in enumerate(nums):
            if target - num in pairs:
                return [i, pairs[target - num]]
            pairs[num] = i
        
        return []
```

### 3. Two-Pointer Approach (For Sorted Arrays)
- **Time Complexity:** O(N log N) (due to sorting) or O(N) if already sorted.
- **Space Complexity:** O(1)
- **Idea:** Sort the array and use two pointers from both ends to find the sum.

#### Python Implementation
```python
class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]:
        nums = [(num, i) for i, num in enumerate(nums)]
        nums.sort()
        left, right = 0, len(nums) - 1
        
        while left < right:
            sum_val = nums[left][0] + nums[right][0]
            if sum_val == target:
                return [nums[left][1], nums[right][1]]
            elif sum_val < target:
                left += 1
            else:
                right -= 1
        
        return []
```

## Summary
| Approach | Time Complexity | Space Complexity | Best For |
|----------|----------------|------------------|----------|
| Brute Force | O(N^2) | O(1) | Small lists |
| HashMap / Dictionary | O(N) | O(N) | General case |
| Two-Pointer | O(N log N) (Sorting) / O(N) (If sorted) | O(1) | Sorted lists |

Each approach has its own trade-offs, but the HashMap approach is usually the best for general cases.
