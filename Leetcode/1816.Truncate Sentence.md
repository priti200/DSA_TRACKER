# Truncate Sentence Problem

## Approach

The problem requires us to truncate a sentence such that only the first `k` words remain.

## Approaches

### 1. Brute Force Approach (String Splitting and Concatenation)
- **Time Complexity:** O(N)
- **Space Complexity:** O(N)
- **Idea:** Split the string into words, take the first `k`, and join them back.

#### Python Implementation
```python
class Solution:
    def truncateSentence(self, s: str, k: int) -> str:
        s = s.split()
        res = ''

        for i in range(k):
            res += s[i] + " "
        
        return res.rstrip()
```

### 2. Optimized Approach (Using Join Function)
- **Time Complexity:** O(N)
- **Space Complexity:** O(N)
- **Idea:** Directly join the first `k` words after splitting.

#### Python Implementation
```python
class Solution:
    def truncateSentence(self, s: str, k: int) -> str:
        return " ".join(s.split()[:k])
```

### 3. Two-Pointer Approach (Efficient Traversal)
- **Time Complexity:** O(N)
- **Space Complexity:** O(1)
- **Idea:** Use a pointer to count spaces and truncate at the correct position.

#### C++ Implementation
```cpp
#include <string>
using namespace std;

class Solution {
public:
    string truncateSentence(string s, int k) {
        int spaceCount = 0;
        for (int i = 0; i < s.length(); i++) {
            if (s[i] == ' ') {
                spaceCount++;
                if (spaceCount == k) {
                    return s.substr(0, i);
                }
            }
        }
        return s;
    }
};
```

## Summary
| Approach | Time Complexity | Space Complexity | Best For |
|----------|----------------|------------------|----------|
| Brute Force (Loop & Concatenation) | O(N) | O(N) | Basic implementation |
| Optimized (Join Function) | O(N) | O(N) | Simple & efficient |
| Two-Pointer | O(N) | O(1) | Space-efficient |

Each approach has trade-offs, but the **Optimized Join Function** method is the most readable and efficient in Python, while **Two-Pointer** is best for C++.
