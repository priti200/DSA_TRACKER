# Contains Duplicate Problem

## Approach

The problem requires us to determine whether an array contains any duplicate elements.

## Approaches

### 1. Brute Force Approach
- **Time Complexity:** O(N^2)
- **Space Complexity:** O(1)
- **Idea:** Compare every element with every other element.

#### C++ Implementation
```cpp
class Solution {
public:
    bool containsDuplicate(vector<int>& nums) {
        int Max = INT_MIN;
        int Min = INT_MAX;

        for (int i = 0; i < nums.size(); i++) {
            if (nums[i] > Max || nums[i] < Min) {
                Max = max(nums[i], Max);
                Min = min(nums[i], Min);
            } else {
                for (int j = 0; j < i; j++) {
                    if (nums[i] == nums[j]) {
                        return true;
                    }
                }
            }
        }
        return false;
    }
};
```

### 2. HashMap / Dictionary Approach (Optimized)
- **Time Complexity:** O(N)
- **Space Complexity:** O(N)
- **Idea:** Use a hashmap to track occurrences of numbers.

#### C++ Implementation
```cpp
#include <unordered_map>
using namespace std;

class Solution {
public:
    bool containsDuplicate(vector<int>& nums) {
        unordered_map<int, int> map;

        for (int i : nums) {
            if (map.count(i)) {
                return true;
            }
            map[i] = 1;
        }
        return false;
    }
};
```

### 3. Sorting Approach
- **Time Complexity:** O(N log N)
- **Space Complexity:** O(1)
- **Idea:** Sort the array and check for adjacent duplicates.

#### Python Implementation
```python
class Solution:
    def containsDuplicate(self, nums: List[int]) -> bool:
        nums.sort()
        for i in range(1, len(nums)):
            if nums[i] == nums[i - 1]:
                return True
        return False
```

### 4. HashSet Approach (Most Efficient)
- **Time Complexity:** O(N)
- **Space Complexity:** O(N)
- **Idea:** Use a hash set to track seen numbers.

#### Python Implementation
```python
class Solution:
    def containsDuplicate(self, nums: List[int]) -> bool:
        return len(set(nums)) < len(nums)
```

## Summary
| Approach | Time Complexity | Space Complexity | Best For |
|----------|----------------|------------------|----------|
| Brute Force | O(N^2) | O(1) | Small datasets |
| HashMap | O(N) | O(N) | General case |
| Sorting | O(N log N) | O(1) | If sorting is acceptable |
| HashSet | O(N) | O(N) | Fastest lookup |

Each approach has trade-offs, but the **HashSet approach** is the most efficient in most cases.
