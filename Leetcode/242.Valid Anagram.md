# Valid Anagram Problem

## Approach

The problem requires us to determine if two strings are anagrams, meaning they contain the same characters with the same frequencies.

## Approaches

### 1. Sorting Approach
- **Time Complexity:** O(N log N)
- **Space Complexity:** O(1)
- **Idea:** Sort both strings and compare if they are equal.

#### Python Implementation
```python
class Solution:
    def isAnagram(self, s: str, t: str) -> bool:
        return sorted(s) == sorted(t)
```

### 2. Frequency Count Approach (Optimized)
- **Time Complexity:** O(N)
- **Space Complexity:** O(1) (Since the alphabet size is fixed at 26)
- **Idea:** Maintain a frequency count of each character and compare counts.

#### C++ Implementation
```cpp
#include <vector>
using namespace std;

class Solution {
public:
    bool isAnagram(string s, string t) {
        vector<int> alpha(26, 0);

        for (auto i : s) {
            alpha[i - 'a']++;
        }

        for (auto i : t) {
            alpha[i - 'a']--;
        }

        for (auto i : alpha) {
            if (i != 0) {
                return false;
            }
        }
        return true;
    }
};
```

### 3. HashMap Approach
- **Time Complexity:** O(N)
- **Space Complexity:** O(N)
- **Idea:** Use a dictionary/hashmap to count character occurrences.

#### Python Implementation
```python
from collections import Counter

class Solution:
    def isAnagram(self, s: str, t: str) -> bool:
        return Counter(s) == Counter(t)
```

### 4. Bit Manipulation Approach (For lowercase letters only)
- **Time Complexity:** O(N)
- **Space Complexity:** O(1)
- **Idea:** Use bitwise XOR to check if character frequencies match.

#### Python Implementation
```python
class Solution:
    def isAnagram(self, s: str, t: str) -> bool:
        if len(s) != len(t):
            return False
        xor_val = 0
        for c1, c2 in zip(s, t):
            xor_val ^= ord(c1) ^ ord(c2)
        return xor_val == 0
```

## Summary
| Approach | Time Complexity | Space Complexity | Best For |
|----------|----------------|------------------|----------|
| Sorting | O(N log N) | O(1) | Simplicity |
| Frequency Count | O(N) | O(1) | Optimal solution for small alphabets |
| HashMap | O(N) | O(N) | General case with varying character sets |
| Bit Manipulation | O(N) | O(1) | Lowercase letters only |

Each approach has its trade-offs, but the frequency count method is the most efficient for English alphabet anagram checking.
