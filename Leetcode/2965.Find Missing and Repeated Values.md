# Find Missing and Repeated Values Problem

## Approach

The problem requires us to identify two values in an `n x n` grid:
- The repeated value (appears twice)
- The missing value (does not appear at all)

## Approaches

### 1. Frequency Count Approach (Using Array)
- **Time Complexity:** O(N^2)
- **Space Complexity:** O(N)
- **Idea:** Store the frequency of each number in an auxiliary array.

#### C++ Implementation
```cpp
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> findMissingAndRepeatedValues(vector<vector<int>>& grid) {
        int n = grid.size() * grid.size();
        vector<int> arr(n, 0);

        for (int i = 0; i < grid.size(); i++) {
            for (int j = 0; j < grid.size(); j++) {
                arr[grid[i][j] - 1]++;
            }
        }

        int doubs, none;
        for (int i = 0; i < n; i++) {
            if (arr[i] == 0) none = i + 1;
            if (arr[i] == 2) doubs = i + 1;
        }

        return {doubs, none};
    }
};
```

### 2. HashSet Approach
- **Time Complexity:** O(N^2)
- **Space Complexity:** O(N)
- **Idea:** Use a HashSet to track seen numbers and identify the repeated and missing values.

#### Python Implementation
```python
class Solution:
    def findMissingAndRepeatedValues(self, grid: List[List[int]]) -> List[int]:
        seen = set()
        n = len(grid) * len(grid)
        duplicate, missing = -1, -1

        for row in grid:
            for num in row:
                if num in seen:
                    duplicate = num
                seen.add(num)

        for i in range(1, n + 1):
            if i not in seen:
                missing = i
                break

        return [duplicate, missing]
```

### 3. Mathematical Approach (Using Sum and Square Sum Formulas)
- **Time Complexity:** O(N^2)
- **Space Complexity:** O(1)
- **Idea:** Compute expected sum and square sum, then solve for the missing and duplicate values.

#### Python Implementation
```python
class Solution:
    def findMissingAndRepeatedValues(self, grid: List[List[int]]) -> List[int]:
        n = len(grid) * len(grid)
        expected_sum = n * (n + 1) // 2
        expected_square_sum = sum(i * i for i in range(1, n + 1))
        actual_sum = actual_square_sum = 0

        for row in grid:
            for num in row:
                actual_sum += num
                actual_square_sum += num * num

        diff1 = expected_sum - actual_sum  # missing - duplicate
        diff2 = (expected_square_sum - actual_square_sum) // diff1  # missing + duplicate
        
        missing = (diff1 + diff2) // 2
        duplicate = missing - diff1
        
        return [duplicate, missing]
```

## Summary
| Approach | Time Complexity | Space Complexity | Best For |
|----------|----------------|------------------|----------|
| Frequency Count | O(N^2) | O(N) | Simple and intuitive |
| HashSet | O(N^2) | O(N) | Faster lookup with sets |
| Mathematical | O(N^2) | O(1) | Optimized for minimal space |
