# Permutation Difference Problem

## Approach

The problem requires us to calculate the permutation difference between two strings `s` and `t`, where `t` is a permutation of `s`. The difference is computed as the sum of absolute differences between corresponding character positions in `s` and `t`.

## Approaches

### 1. HashMap Approach (Index Mapping)
- **Time Complexity:** O(N)
- **Space Complexity:** O(N)
- **Idea:** Store character positions in a hashmap and compute the absolute positional difference.

#### Python Implementation (Optimized Variable Names)
```python
class Solution:
    def findPermutationDifference(self, s: str, t: str) -> int:
        position_map = {char: idx for idx, char in enumerate(t)}
        total_difference = sum(abs(i - position_map[s[i]]) for i in range(len(s)))
        return total_difference
```

### 2. Brute Force Approach (Nested Loops)
- **Time Complexity:** O(N^2)
- **Space Complexity:** O(1)
- **Idea:** For each character in `s`, find its index in `t` using a loop and compute the difference.

#### Python Implementation
```python
class Solution:
    def findPermutationDifference(self, s: str, t: str) -> int:
        total_difference = 0
        
        for i in range(len(s)):
            for j in range(len(t)):
                if s[i] == t[j]:
                    total_difference += abs(i - j)
                    break
        
        return total_difference
```

### 3. C++ Implementation (Using HashMap)
- **Time Complexity:** O(N)
- **Space Complexity:** O(N)
- **Idea:** Store character positions in an unordered map and compute the absolute positional difference.

#### C++ Implementation
```cpp
#include <unordered_map>
#include <cmath>
#include <string>
using namespace std;

class Solution {
public:
    int findPermutationDifference(string s, string t) {
        unordered_map<char, int> positionMap;
        for (int i = 0; i < t.size(); i++) {
            positionMap[t[i]] = i;
        }
        
        int totalDifference = 0;
        for (int i = 0; i < s.size(); i++) {
            totalDifference += abs(i - positionMap[s[i]]);
        }
        
        return totalDifference;
    }
};
```

## Summary
| Approach | Time Complexity | Space Complexity | Best For |
|----------|----------------|------------------|----------|
| HashMap (Index Mapping) | O(N) | O(N) | Efficient and simple |
| Brute Force (Nested Loops) | O(N^2) | O(1) | No extra space, but slow |
| C++ HashMap | O(N) | O(N) | Optimized for speed |
