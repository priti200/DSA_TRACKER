# Group Anagrams Problem

## Approach

The problem requires us to group anagrams together. Two words are anagrams if they contain the same characters in a different order.

## Approaches

### 1. Sorting-Based Approach
- **Time Complexity:** O(N * K log K), where N is the number of words and K is the average word length.
- **Space Complexity:** O(NK) for storing grouped anagrams.
- **Idea:** Sort each word and use the sorted version as a key to group anagrams.

#### Python Implementation (Optimized Variable Names)
```python
from collections import defaultdict

class Solution:
    def groupAnagrams(self, words: List[str]) -> List[List[str]]:
        anagram_groups = defaultdict(list)

        for word in words:
            sorted_word = ''.join(sorted(word))
            anagram_groups[sorted_word].append(word)
        
        return list(anagram_groups.values())
```

### 2. Sorting-Based Approach in C++
- **Time Complexity:** O(N * K log K)
- **Space Complexity:** O(NK)
- **Idea:** Sort each word and use an unordered map to group them.

#### C++ Implementation
```cpp
#include <vector>
#include <string>
#include <unordered_map>
#include <algorithm>
using namespace std;

class Solution {
public:
    vector<vector<string>> groupAnagrams(vector<string>& words) {
        unordered_map<string, vector<string>> anagramGroups;
        
        for (string word : words) {
            string sortedWord = word;
            sort(sortedWord.begin(), sortedWord.end());
            anagramGroups[sortedWord].push_back(word);
        }
        
        vector<vector<string>> result;
        for (auto& pair : anagramGroups) {
            result.push_back(pair.second);
        }
        return result;
    }
};
```

### 3. Character Frequency Count Approach
- **Time Complexity:** O(NK), where K is the length of the longest word.
- **Space Complexity:** O(NK)
- **Idea:** Use character frequency count instead of sorting.

#### Python Implementation
```python
from collections import defaultdict

class Solution:
    def groupAnagrams(self, words: List[str]) -> List[List[str]]:
        anagram_groups = defaultdict(list)
        
        for word in words:
            char_count = [0] * 26  # Assuming lowercase English letters
            for char in word:
                char_count[ord(char) - ord('a')] += 1
            
            anagram_groups[tuple(char_count)].append(word)
        
        return list(anagram_groups.values())
```

## Summary
| Approach | Time Complexity | Space Complexity | Best For |
|----------|----------------|------------------|----------|
| Sorting-Based | O(N * K log K) | O(NK) | Simple and efficient |
| HashMap (C++ & Python) | O(N * K log K) | O(NK) | Easy implementation |
| Character Frequency Count | O(NK) | O(NK) | Faster for short words |
